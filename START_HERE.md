## 🚨 Troubleshooting Quick Guide

### Issue: App won't start
```
Solution: Run as Administrator
  Right-click Command Prompt → "Run as administrator"
```

### Issue: Forecasts not showing
```
Solution: Wait for models to train
  After 2 hours, forecasts should appear
  Or: Manually visit more websites for faster data collection
```

### Issue: Models not training
```
Solution: Ensure you have enough data
  Minimum: 48 data points (~2 hours)
  Better: 200+ data points (several hours)
```

### Issue: Import errors
```
Solution: Install missing dependencies
  pip install -r requirements.txt
  pip install pystan==2.19.1.1 prophet
  pip install tensorflow
```
